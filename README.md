# ZTE F50 Pro root及安装高级后台指南

这份指南记录的是：**中兴 F50 Pro（MU3356）B28 怎么备份、取得 root，再装上 UFI-TOOLS 高级后台。** 我们把实际走过的步骤和踩过的坑写下来，方便你先判断能不能做，再一步步核对。

> **🔴 先别急着刷：有无法开机、丢数据、丢无线校准的风险，也会影响启动安全、OTA 和保修。没有自己的完整原厂备份、6 MiB TrustOS 原件和可用的下载模式恢复路径，就不要刷。**
>
> 这不是一键 root 包。只在下面这一台设备、这一版构建上成功过，不能保证其他 F50 Pro 都一样。**离线制作 root 镜像仍需要自己实现和审查；参考 Magisk APK 的精确来源还没有完全核实，不能当成已打通的零基础一条龙教程。**

## 先看你是哪种情况

- **还没 root：** 从[第 0 章：一步步走](docs/00-walkthrough.md)开始。先备份，别跳到刷写命令。
- **已经 root，只想装高级后台：** 先确认 `su -c id` 真能返回 root，再看[第 5 章：安装高级后台](docs/05-advanced-backend.md)。不用为了装后台重新刷分区。
- **只是想找现成镜像直接刷：** 这里不提供别人机器的镜像，也不建议这么做。

## 每一步怎么读

- 🟢 **只读检查**：不主动改分区，但输出和备份可能包含隐私，别公开。
- 🟡 **安装 / 配置**：会改应用、权限或启动脚本；先备份，改错可能导致后台打不开。
- 🔴 **高风险 / 安全敏感**：刷分区可能无法开机；开放持久 root 则会扩大攻击面。两者都要单独确认。
- ⛔ **停在这里**：条件不满足就别继续，不要靠换包、换槽或反复重试碰运气。

## 这次到底测了什么

| 项目 | 实际情况 |
| --- | --- |
| 设备 | ZTE F50 Pro **MU3356**，Android 15 |
| 固件 | `F50ProV1.0.0B28`，构建 `20260818.180242` |
| 原厂指纹 | `ZTE/MU3356/MU3356:15/AP3A.240905.015.A2/20260818.180242:user/release-keys` |
| 活动槽 | **A / `_a`**；下载器、misc CRC、Android 属性交叉核对。本机 `init_boot_b` 为空 |
| 刷了哪些 | 只有 `init_boot_a` 和**从本机原件生成的** `trustos_a`；没有刷 B 槽、基带、校准、IMEI 或分区表 |
| root | `/debug_ramdisk/su -c id` 返回 `uid=0(root)`；Magisk `1e3edb88:MAGISK:R` / **28103** |
| 重启 | 正常重启一次后，ADB、root、Magisk 启动阶段和两个分区的 live SHA256 检查通过 |
| 高级后台 | UFI-TOOLS **4.0.0**，包名 `com.minikano.f50_sms`；网页获取和登录后的 Root API 在正常重启后通过 |
| 恢复 | 实际做过原厂 `init_boot_a` 单分区恢复和回读；**完整双分区回退仅准备方案，没有实测** |
| 没测完 | 长期稳定性、OTA、恢复出厂、断电恢复、全部无线业务；后台每个按钮和手机视觉效果也没逐项验收 |

**这次只刷 init_boot 曾经循环重启。** 我们先恢复原件并核对回读，之后才评估本机 TrustOS；后来还修正了 ADB 启动时序。别把“写入完成”或“网页打开了”当成全部成功。

## 安全和隐私，别省略

- 备份里可能有 IMEI、校准和账户信息，私下保存两份；不发布原始日志、密码、卡身份或 ADB 密钥。
- 本次方案长期允许 shell UID 提权，还用了网络 ADB。**5555 和高级后台都不能直接暴露公网，也别放到不可信局域网。** 预置公钥不代表已经验证 ADB 拒绝陌生主机；这项负向测试尚未完成。
- 高级后台使用 HTTP，不是 HTTPS。密码不代表流量已加密；陌生网络上不要输入凭据，也不要导入来历不明的插件。
- 不提供固件、Magisk APK、TrustOS、下载器或驱动二进制；从可信上游取得，核对来源、许可与哈希。

## eSIM 是另外一件事

**root 成功不等于 eSIM 可用。** [eSIM 管理模块](https://github.com/yukinsnow/f50pro-esim-manager)是独立的实验性预发布：**缺乏充分验证**；信息读取通过实机检查，启停、昵称、删除、下载和通知发送没有真实写卡验证。安装高级后台不会自动安装它，也不会自动改你的卡。
